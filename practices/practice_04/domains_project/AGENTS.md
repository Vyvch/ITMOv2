# Правила проекта

Контракт: docs/requirements.md
Пример теста: tests/test_main.py
Проверка: python scripts/check.py

## Подключенные скиллы (Skills)
Мы используем следующие скиллы для поддержания качества кода:
1. **fastapi** - для правильной архитектуры и использования FastAPI.
2. **python-project-structure** - для грамотного структурирования Python-проекта.
3. **python-code-style** - для чистого кода с типизацией и PEP8.
4. **python-error-handling** - для правильной обработки исключений (важно при парсинге).
5. **frontend-design** - для написания чистого и красивого UI на HTML/JS.
6. **tdd** - для разработки через тестирование.
7. **code-review** - для жесткого код-ревью субагентами.

Не меняй контракт и runner без поручения.
