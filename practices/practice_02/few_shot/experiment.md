# Few-shot

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Артефакт Практики 1: `tests_integration.md`
- Что хотим улучшить: Перевести абстрактные описания тестов ("Мокируем ошибку") в строгие сценарии с указанием фреймворка и шагов.

## Примеры

### Хороший результат
### Сценарий: Обработка 500 ошибки от GitHub API
* **Цель:** Убедиться, что сервис корректно обрабатывает сбой API.
* **Инструмент:** `pytest`, `pytest-httpx`.
* **Шаги:**
  1. В фикстуре `httpx_mock` задать роут `POST https://api.github.com/...` с ответом `status_code=500`.
  2. Вызвать обработчик вебхука `client.post("/webhook", json=payload)`.
* **Ожидаемый результат:** Сервис отвечает `202 Accepted`, в логах пишется `error: GitHub API 500`.

Сценарий: LLM упал.

## Что получили

### Сценарий: Таймаут от VseLLM
* **Цель:** Убедиться, что сервис не зависает при долгом ожидании ответа от нейросети.
* **Инструмент:** `pytest`, `pytest-httpx`.
* **Шаги:**
  1. В фикстуре `httpx_mock` настроить роут `POST https://api.vsellm.ru/...` на выброс исключения `httpx.TimeoutException`.
  2. Вызвать обработчик вебхука `client.post("/webhook", json=payload)`.
* **Ожидаемый результат:** Сервис быстро отвечает `202 Accepted`, в логах пишется `error: VseLLM Timeout`.

### Сценарий: Ошибка 503 от VseLLM
* **Цель:** Убедиться, что сервис перехватывает сбой сервиса генерации.
* **Инструмент:** `pytest`, `pytest-httpx`.
* **Шаги:**
  1. В фикстуре `httpx_mock` задать роут `POST https://api.vsellm.ru/...` с ответом `status_code=503`.
  2. Вызвать обработчик вебхука `client.post("/webhook", json=payload)`.
* **Ожидаемый результат:** Сервис отвечает `202 Accepted`, в логах пишется `error: VseLLM 503 Service Unavailable`.
