## Описание изменения
Добавлен метод ReviewService.review, который формирует промпт с содержимым diff и запрашивает LLM, возвращая словарь с ключом "comment". В API появился POST /api/reviews, который принимает JSON и передаёт поле payload["diff"] в review_service.review; также сохранён эндпоинт /health.

## Риски
- app/api.py, create_review, строка 37 — доступ к payload["diff"] без проверки приводит к KeyError при отсутствии поля diff. Доказательство: в diff видно прямой индексируемый доступ `return review_service.review(payload["diff"])` (строка 37). Проверка: отправить POST /api/reviews с пустым JSON и ожидать 500 из-за KeyError.
- app/review_service.py, review, строка 21 — исключения из self.llm.generate(prompt) не обрабатываются, что приведёт к 500 на уровне API при сбое LLM. Доказательство: в diff вызов `answer = self.llm.generate(prompt)` (строка 21) без try/except и маппинга ошибок. Проверка: подставить LLM-реализацию, у которой generate выбрасывает Exception, и вызвать review; ожидать необработанное исключение.

## Проверки
- Запустить приложение и проверить health:
  curl -s http://localhost:8000/health
- Воспроизвести KeyError:
  curl -s -X POST http://localhost:8000/api/reviews -H 'Content-Type: application/json' -d '{}'
- Позитивный путь:
  curl -s -X POST http://localhost:8000/api/reviews -H 'Content-Type: application/json' -d '{"diff":"diff --git a b"}'
- Юнит-тест ReviewService с фейковым LLM, у которого generate выбрасывает Exception, и убедиться, что исключение пробрасывается.
