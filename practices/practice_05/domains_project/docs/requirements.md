# Требования к проекту

Проект: Мини-сайт и CLI для просмотра освобождающихся доменов.
Тематика: домены .ru, .su, .рф.

**Фича А (Задача 1): Базовый функционал**
- Программа должна получать список доменов, которые освобождаются сегодня, завтра, послезавтра и в другие дни.
- Поддержка фильтров по датам (Сегодня, Завтра, Послезавтра), пагинации и поиска по имени.
- Использовать внешний MCP (например, 2captcha) для обхода блокировок и парсинга сайта `auction.nic.ru` (если потребуется).
- Выводить полученный список пользователю.
- Обязательно реализовать два интерфейса: CLI-утилиту и Web-приложение (FastAPI мини-сайт).

**Фича B (Задача 2): Умный поиск (Top-20)**
- Внедрить логику выбора 20 "самых крутых" доменов.
- Использовать нейросеть (LLM) для оценки "крутости" домена.
- **Сначала реализовать логику** в нашем собственном MCP-сервере (`mcp_whois.py`), чтобы он реально умел получать данные WHOIS.
- **Затем использовать** этот обновленный MCP-сервер для подтягивания дополнительной информации о выбранных топ-20 доменах.
