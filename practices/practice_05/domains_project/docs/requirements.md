# Требования к проекту

Проект: Мини-сайт и CLI для просмотра освобождающихся доменов.
Тематика: домены .ru, .su, .рф.

**Фича А (Задача 1): Базовый функционал**
- Программа должна получать список доменов, которые освобождаются сегодня, завтра, послезавтра и в другие дни.
- Поддержка фильтров по датам (Сегодня, Завтра, Послезавтра), пагинации и поиска по имени.
- Использовать внешний MCP (например, 2captcha) для обхода блокировок и парсинга сайта `auction.nic.ru` (если потребуется).
- Выводить полученный список пользователю.
- Обязательно реализовать два интерфейса: CLI-утилиту и Web-приложение (FastAPI мини-сайт).

**Фича B (Задача 2): Умный поиск (Top-20)**
- Внедрить логику выбора 20 "самых крутых" доменов.
- Использовать нейросеть (LLM) для оценки "крутости" домена.
- **Сначала реализовать логику** в нашем собственном MCP-сервере (`mcp_whois.py`), чтобы он реально умел получать данные WHOIS.
- **Затем использовать** этот обновленный MCP-сервер для подтягивания дополнительной информации о выбранных топ-20 доменах.

**Фича C (Задача 3): Regex-поиск**
- Во вкладке «Все домены» поиск по имени поддерживает регулярные выражения.
- Включение: кнопка `.*` рядом с полем поиска. Regex-режим включается автоматически, если в запросе есть хотя бы один из символов `^ $ * + ? ( ) [ ] { } | \`; пока они есть, кнопка подсвечена и не выключается. Без спецсимволов и без нажатой кнопки работает обычный поиск по подстроке (точка буквальная).
- Сопоставление выполняется на сервере: `GET /api/domains?regex=<выражение>` возвращает домены, в имени которых есть совпадение в любой позиции (якоря `^`/`$` пишет пользователь). Без параметра или с пустым значением ответ прежний.
- Синтаксис RE2: линейное время, без обратных ссылок и lookaround — защита от ReDoS. Длина выражения — не более 256 символов.
- Регистр не учитывается, в том числе для кириллицы; домены `.рф` ищутся в кириллической форме.
- Невалидное или неподдерживаемое выражение → HTTP 400 с сообщением в `detail`. В интерфейсе — красная рамка у поля и текст ошибки под ним (выводится как текст, без HTML); список остаётся последним валидным результатом, а если его ещё не было — показывается полный список с учётом фильтра дат.
- Рядом с полем — счётчик найденных доменов с учётом фильтров дат и поиска.
- Вне scope: CLI, отдельный фильтр по зонам, вкладки Топ-20, подсветка совпадений, состояние поиска в URL, поиск по punycode.
