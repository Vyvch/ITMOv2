# Quickstart: проверка истории домена в веб-архиве (сервер)

Форматы ответов — `specs/wayback-contract.md`; сущности — [data-model.md](data-model.md);
матрица тестов — [contracts/wayback-api.md](contracts/wayback-api.md).

## Требования

- Python 3.14, зависимости из `requirements.txt` (новых нет):

```bash
pip install -r requirements.txt
```

## 1. Автоматическая проверка (обязательная, без сети)

```bash
python scripts/check.py
```

Ожидается: код выхода 0 и `OK: Все тесты пройдены!`. Покрытие фичи — `tests/test_wayback.py`
(нормализация, разбор CDX, кэш, очередь, «429», таймаут) и `tests/test_wayback_api.py`
(статусы, тела и `Retry-After` по контракту). Отдельно, во время разработки:

```bash
python -m unittest tests.test_wayback tests.test_wayback_api -v
```

## 2. Ручная проверка с реальным архивом (необязательная, нужна сеть)

Запустить сервер:

```bash
uvicorn api:app --reload
```

| # | Запрос | Ожидается |
|---|--------|-----------|
| M1 | `curl -i "http://127.0.0.1:8000/api/wayback?domain=example.ru"` | `200`, `snapshot_count > 0`, `first.url`/`last.url` открываются в браузере, `cached: false` |
| M2 | тот же запрос повторно | `200`, `cached: true`, ответ мгновенный, в журнале нет нового обращения к архиву |
| M3 | `curl -i "http://127.0.0.1:8000/api/wayback?domain=%D0%BF%D1%80%D0%B8%D0%BC%D0%B5%D1%80.%D1%80%D1%84"` (`пример.рф`) | `domain` в ответе — кириллицей; запрос с `xn--e1afmkfd.xn--p1ai` отдаётся из кэша |
| M4 | домен заведомо без снимков, например `curl -i "http://127.0.0.1:8000/api/wayback?domain=zq7x9k2m4p8w.ru"` | `200`, `snapshot_count: 0`, `first: null`, `last: null` |
| M5 | `curl -i "http://127.0.0.1:8000/api/wayback?domain=example.com"` и без параметра | `400`, `code: invalid_domain` |
| M6 | 20 разных доменов одновременно (например, открыть вкладку Топ-20 после реализации 001-wayback-ui) | обращения к архиву не чаще 1 раза в 3 с (20 в минуту), архив не блокирует соединения; часть ответов `202` с `Retry-After`; повтор через указанное время даёт `200` из кэша; все 20 — в кэше не позже чем через ~70 с (SC-006) |
| M7 | перезапустить сервер и повторить M1 | `200`, `cached: true` — кэш прочитан из `.cache/wayback_cache.json` |

Сценарии «429» и таймаута архива вручную не воспроизводятся — они покрыты тестами из п. 1.

## 3. Критерии готовности

- п. 1 проходит (принцип II конституции);
- M1–M7 дают ожидаемые ответы (M6 — проверка SC-006 на реальном архиве);
- `git status` не показывает `.cache/wayback_cache.json`;
- код-ревью (скилл `code-review`) с проверкой принципа IV: таймауты, конкретные исключения,
  нет `500` и стектрейсов в ответах.
