# Quickstart: проверка фичи «История домена в веб-архиве» (интерфейс)

## Предусловия

- Python 3.14 с зависимостями из `requirements.txt`.
- Node.js ≥ 18 в `PATH` (`node --version`) — только для тестов логики `WaybackCore`, без npm.
  Без node эти тесты пропускаются с причиной в выводе; статические проверки работают всегда.
- Для ручной проверки историй 2–3 — серверный эндпоинт `GET /api/wayback` из
  `specs/002-wayback-api` (контракт `specs/wayback-contract.md`). Истории 1 и 4 от него не зависят.

## 1. Автоматическая проверка

```bash
python scripts/check.py
```

Ожидается `OK: Все тесты пройдены!`. Тесты фичи — `tests/test_wayback_ui.py`:

| Группа | Что доказывает | Источник требований |
|--------|----------------|---------------------|
| Статические проверки `index.html` | нет HTML-вставок внешних данных, `fetch` только к `/api/...`, якоря DOM на месте | FR-020…FR-022, принципы IV–V, `contracts/ui-contract.md` §2, §4 |
| `archiveUrl`, `formatDate`, `formatCount`, `safeHref` | ссылки, punycode для `.рф`, `ДД.ММ.ГГГГ` без часовых поясов, `100 000+`, ссылки на снимки только `https://web.archive.org/...` | FR-005, FR-009, FR-009a, FR-010 |
| `classifyResponse` (табличный) | 200 / 0 снимков / 202 / 503 / 504 / 502 / 400 / не JSON / неизвестный `code` | FR-012a, FR-012c, FR-013 |
| `createHistoryLoader` на виртуальных часах | повтор 202 через `retry_after`, дедлайн 2 мин, таймаут 20 с, отмена, запоминание | FR-013…FR-015, пограничные случаи |
| `createLimiter`, `createCountdown` | не более 4 параллельных запросов, слот не держится во время ожидания `202`; отсчёт «Повторить через N с» | R9, FR-012b, SC-004 |

## 2. Ручная проверка в браузере

```bash
fastapi dev api.py
```

Открыть `http://127.0.0.1:8000/`.

1. **Карточка домена (US1)**. Во «Всех доменах» кликнуть по любому домену → открылся диалог
   с именем, датой, ссылкой и кнопкой «Запросить историю». Во вкладке «Сеть» DevTools нет
   запроса `/api/wayback`. Ссылка открывает `web.archive.org/web/*/<домен>` в новой вкладке; для
   `.рф` в адресе punycode (`xn--…`). Esc, «Закрыть» и клик по фону закрывают диалог, страница
   пагинации и фильтры прежние. Tab + Enter на карточке тоже открывает диалог.
2. **История (US2)**. «Запросить историю» → «Загрузка истории…» → число снимков и две даты
   со ссылками. Закрыть и открыть снова → результат сразу, без запроса.
3. **Топ-20 (US3)**. Открыть «Топ-20 (Сегодня)» → в колонке «Веб-архив» каждой строки сразу
   «Загрузка истории…», затем итог; в «Сети» одновременно не больше 4 запросов `/api/wayback`;
   при пустом кэше сервера все строки получают итог ≤ 2 минут. Переключиться на «Завтра» во время
   загрузки → старые ответы в новый список не попадают.
4. **Безопасный вывод (US4)**. Визуально строки Топ-20 как раньше (подписи WHOIS жирные, «Свободен»
   зелёным, ошибка красным). Проверка разметки: в DevTools подменить ответ `/api/top`
   (Overrides) обоснованием `<img src=x onerror=alert(1)>` → текст виден буквально, alert нет.
5. **Ошибки (US2, FR-012…FR-012c)**. Через DevTools Overrides подменить ответ `/api/wayback`:
   503 `archive_overloaded` + `Retry-After: 5` → «Повторить через 5 с» с отсчётом;
   400 `invalid_domain` → текст без кнопки; 504 → «Веб-архив не ответил вовремя».

## 3. Критерий готовности

`python scripts/check.py` проходит без пропусков на машине с node; ручные шаги 1 и 4 выполнены;
шаги 2, 3, 5 — после готовности серверной фичи или на подменённых ответах.
